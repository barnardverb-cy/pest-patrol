# Later ideas

These features would make the game feel more complete.

- Power-ups and special abilities: Add temporary boosts such as a time-slow, bomb blast, or auto-snap swatter. A few rare abilities can help during busy waves.
- Multiple levels with rising difficulty: Keep the same rules, but unlock new stages with faster bugs, more targets, and tighter spacing. A score target or boss wave can mark each level.
- Saved high scores: Save the best score in browser storage so returning players can chase a new record.

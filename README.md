# Pest Patrol

Pest Patrol is a simple shooting gallery game where you shoo cartoon mosquitoes out of a Filipino sari-sari store before closing time.

## How to Play
- Move your mouse to aim.
- Left-click to shoot mosquitoes.
- Earn points by hitting mosquitoes. Smaller mosquitoes are worth more points.
- Score as many points as possible before the 60-second timer runs out.
- Click **Play Again** to restart the game.

## How to Run It
1. Download `index.html` from the repository.
2. Open the file in a web browser.
3. Start playing!

## Built With
- Plain HTML, CSS, and JavaScript in a single `index.html` file.
